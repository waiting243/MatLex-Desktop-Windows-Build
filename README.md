# MatLex Desktop v11.4.2

这是以 MatLex Android v11.3.1 稳定功能为基础持续重构的 Windows 桌面版工程。专业英语 999 词、面试问答、概念复习、错词、熟词、学习进度、上一词、液态玻璃界面等原有功能继续保留。

## 电脑屏幕适配

桌面版在窗口宽度达到 980px 后自动启用电脑布局：

- 首页三大模块横向排布，充分使用宽屏空间。
- 原手机底部导航变成左侧竖向导航栏，仍然只使用同一个共享导航组件。
- 专业英语首页采用左右双栏，左侧是学习入口与统计，右侧是学习设置和声音设置。
- 面试问答、概念复习、题库和概念库使用更宽的内容区域，列表在宽屏下自动双列。
- 单词库在电脑上使用双列目录，减少大面积空白。
- 做题页面扩大到桌面阅读宽度，四个选项自动两列排列。
- 手机上的底部弹层在桌面版中改为屏幕中央对话框。
- 窗口缩小时仍可退回原有紧凑布局。

## 最省事的 Windows 构建方法

把整个工程上传到 GitHub 仓库根目录，然后进入 Actions，运行 `MatLex Desktop Windows Build`。

构建成功后，在 Artifacts 中下载：

`MatLex-Desktop-Windows-v11.4.2`

其中会包含 Windows 安装版 EXE 和便携版 EXE。

## 本地构建

电脑需要安装 Node.js 20 或更高版本，以及 Python 3.10 或更高版本。然后双击：

`BUILD_WINDOWS.bat`

脚本会自动生成 Microsoft Ava 自然语音、安装 Electron 构建依赖，并在 `dist` 文件夹生成 Windows 程序。

## 数据保存

学习记录继续使用浏览器本地存储机制。Electron 会给 MatLex 保留独立的应用数据目录，所以正常升级应用不会清空学习记录。卸载程序默认也不会主动删除用户数据。


## v11.4.2 更新

- 修正面试问答和概念复习右侧学习概览在较矮或较窄电脑窗口中显示不完整的问题。
- 右侧概览的标题、统计和底部按钮固定可见，全部分类进度改为面板内部滚动。
- 980 到 1179px 的窄桌面窗口自动改为上下布局，禁止右侧栏被窗口裁切。
- 专业英语右侧学习设置增加视口约束，窗口高度不足时可在栏内滚动。
- 桌面学习概览、窗口控件、返回按钮统一使用与全局卡片相同的 Liquid Glass 参数，取消高不透明度的单独白色材质。
- 继续保留 v11.4.1 已完成的自定义标题栏、桌面快捷方式、双栏布局和概念内容修订。
